# Building an Android APK

This turns KiasuJobs (a web app) into an installable Android `.apk` using Capacitor.

## Requirements

- Android Studio installed ([download](https://developer.android.com/studio))
- Node.js + npm (already have it)

## One-Time Setup

Run these in the project root:

```bash
# 1. Install dependencies (includes Capacitor)
npm install

# 2. Make sure your Supabase keys are filled in
#    src/lib/supabase.ts — the APK bundles whatever is in there at build time

# 3. Build the production web app (creates the /dist folder)
npm run build

# 4. Add the Android platform (creates the /android folder)
npx cap add android

# 5. Copy the web build into the Android project
npx cap sync

# 6. (Optional) Generate the app icon from assets
#    Convert public/icons/icon-512.svg to a 1024x1024 PNG at assets/icon.png, then:
npx @capacitor/assets generate --android

# 7. Open the project in Android Studio
npx cap open android
```

## In Android Studio

1. Wait for **Gradle sync** to finish (first time takes a few minutes — watch the bottom status bar)
2. Top menu: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
3. When it finishes, a notification appears bottom-right → click **locate**

The file is at:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

## Distributing to Friends

1. Send them `app-debug.apk` (Google Drive, WhatsApp, email, a download link)
2. On their Android phone: tap the file
3. Android warns about "install from unknown sources" → **Allow / Install anyway**
4. It installs like any other app

## After Making Code Changes

```bash
npm run build
npx cap sync
```

Then rebuild the APK in Android Studio.

## Notes

- **Android only.** iOS does not allow sideloading — that needs the App Store ($99/year).
- **Debug APK** is fine for sharing with friends. The Play Store needs a signed release AAB.
- The `/android` folder is git-ignored — it's regenerated by `npx cap add android`.
- **Your Supabase keys ship inside the APK.** That's expected and safe: the anon key is a public
  client key, and Row Level Security is what actually protects the data. Never put the
  `service_role` key in `src/`.

## Skipping the APK entirely

The app is also a PWA. On an Android phone, open the site in Chrome and use
**⋮ → Add to Home screen** — you get an icon and a full-screen app with no build step. Useful for
quick demos.
